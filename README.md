# 🛒 在线商城系统

## 📖 项目简介
这是一个基于 Java Web 技术开发的在线商城系统，实现了商品展示、用户登录、购物车、订单管理等核心功能。

## 🛠️ 技术栈
- **后端**: Java, Servlet, JDBC
- **前端**: HTML, CSS, JavaScript, Bootstrap, JSP
- **数据库**: MySQL
- **服务器**: Tomcat

## 📂 项目结构


## 🚀 运行步骤
1.  **导入项目**：使用 IDEA/Eclipse 导入 `shop` 项目
2.  **配置数据库**：
    - 创建 MySQL 数据库，执行 `SQL` 文件夹中的脚本
    - 修改项目中数据库连接配置（如 JDBC URL、用户名、密码）
3.  **部署项目**：将项目部署到 Tomcat 服务器
4.  **启动访问**：运行 Tomcat，访问 `http://localhost:8080/shop/`

## ✨ 功能模块
- 用户注册与登录
- 商品分类与列表展示
- 商品详情查看
- 购物车管理
- 订单提交与管理
